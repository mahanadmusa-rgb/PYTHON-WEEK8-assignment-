# Personal Mini-Toolkit

## Project Description
The Personal Mini-Toolkit is a Python program that provides three useful tools through a menu.

## Tools
1. Simple Calculator — performs addition, subtraction, multiplication, and division.
2. To-Do List — allows users to add, view, and remove tasks.
3. Even Number Checker — determines whether a whole number is even or odd.

## Concepts Practiced
- While and for loops
- If, elif, and else conditionals
- Lists and list methods
- Functions
- Input validation and exception handling
- F-strings and comments

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python toolkit.py`.

## Screenshots
The `screenshots` folder contains evidence of the menu, invalid choice handling, and each tool running.

## Reflection
Planning the toolkit helped me organize the program before writing the code. The most challenging part was making the menu return after each tool finished. Testing invalid inputs helped me understand how to prevent a program from crashing. I learned how lists can store changing information in a to-do list. I also practiced loops, conditionals, functions, and f-strings. With one more week, I would add a number-guessing game and save tasks to a file so they remain available after the program closes.
