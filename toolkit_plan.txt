PERSONAL MINI-TOOLKIT — PROJECT PLAN

1. TOOLS

Tool 1: Simple Calculator
The calculator adds, subtracts, multiplies, and divides two numbers.
Concepts: input, variables, conditionals, try/except, and f-strings.

Tool 2: To-Do List
The to-do list allows users to add, view, and remove tasks.
Concepts: lists, loops, conditionals, and f-strings.

Tool 3: Even Number Checker
The checker determines whether a number is even or odd.
Concepts: input, conditionals, the modulo operator, and f-strings.

2. EXACT MENU TEXT

Welcome to My Personal Mini-Toolkit!
Choose a tool:
1. Simple Calculator
2. To-Do List
3. Even Number Checker
4. Quit

3. MENU BEHAVIOUR

The menu repeats until the user chooses Quit.
Invalid choices display a polite error message.
Each tool returns the user to the main menu when finished.

4. DATA AND CONTROL FLOW

A while loop keeps the menu running.
If, elif, and else statements route the user's choice.
A changing list stores to-do tasks.
A for loop displays the tasks.
F-strings display friendly messages.
